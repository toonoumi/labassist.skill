# Agitation schemes

Default to the **standard scheme** unless the user asks for something else
or the developer calls for a special technique.

## Standard (Ilford/Kodak-style, most developers)

- Initial: continuous gentle inversion for the first **10-30 seconds**
  (tap the tank afterward to dislodge air bubbles).
- Ongoing: **4-5 gentle inversions (~5-10 sec) every 30-60 seconds** for the
  remainder of the development time.
- Every 60s is gentler (slightly less contrast/finer apparent grain), every
  30s is the more common default. Pick 30s unless the user has a reason to
  want the other.

## Reduced agitation / stand & semi-stand (Rodinal and similar)

Used to tame contrast in high-brightness-range scenes, common with Rodinal.

- **Semi-stand:** 1 minute continuous initial agitation, then 2-3 gentle
  inversions every 15 minutes, for 45-60+ min total in a very dilute
  developer (e.g. Rodinal 1+100).
- **Stand:** initial agitation only (30-60s), then completely undisturbed
  for 60+ minutes.
- Only suggest these if the user asks for stand/semi-stand or mentions a
  very dilute Rodinal ratio (1+100 or higher) — they're a deliberate
  stylistic choice, not a default.

## Fixer and stop bath agitation

- Stop bath: continuous agitation for the full (short) duration.
- Fixer: agitate continuously for the first 30s, then 5-10 sec every 30-60s
  for the rest of the fix time.
